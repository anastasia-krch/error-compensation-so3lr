# NTf2- dihedral distributions

This chapter compares the two NTf2- backbone dihedrals at 310 K: φ₁ = C₁–S₁–N–S₂ and φ₂ = S₁–N–S₂–C₂. Each joint observation uses both angles from the same anion in the same trajectory frame.

`data/dihedral_histograms_310K.csv` contains the normalised joint histograms for SO3LR, APPLE&P, CL&P, and CL&P-scaled. `figures/dihedral_comparison_310K.png` is the reviewed unfolded figure used in the manuscript; panels (f,g) are the separate marginal distributions of φ₁ and φ₂.

Run `notebooks/plot_dihedrals_310K.ipynb` to regenerate the figure from the CSV.
